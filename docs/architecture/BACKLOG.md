# سجلّ المؤجَّل — Backlog & Technical Debt

**ما رُصد ولم يُبنَ.** كل بند هنا **لا يمنع الإطلاق** — وإلا لكان في الخارطة لا في هذا السجلّ.

> **قاعدة العمل:** ما يمنع التنفيذ أو يكسر الأمن أو يكسر المعمارية **يوقف العمل ويُبلَّغ**.
> وما هو تحسينٌ أو تطويرٌ مستقبليّ **يُسجَّل هنا ويُكمَل التنفيذ** بلا نقاش معماري جديد.

**آخر تحديث:** بعد اعتماد ب٠ معمارياً.
