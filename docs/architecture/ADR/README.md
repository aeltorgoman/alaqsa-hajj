# سجلّات القرار المعماريّ — Architecture Decision Records

القرار المعماريّ الذي يصير **معياراً مُلزِماً للمشروع** يُسجَّل هنا، بملفٍّ واحدٍ
لكلّ قرار، مرقّماً تسلسلياً، **ولا يُعاد ترقيمه أبداً**.

## القواعد

- **الحالة مذكورة دائماً:** `Proposed` · `Approved` · `Superseded by ADR-nnn` ·
  `Withdrawn`.
- **القرار المعتمد لا يُحرَّر في مكانه ليعني شيئاً آخر.** يُستبدل بقرارٍ جديد
  يَنسخه، ويبقى النصُّ المنسوخ ومعه سببُ استبداله — على نهج
  `SECURITY_ARCHITECTURE.md`.
- **دليل الهندسة يُحيل ولا ينسخ.** القاعدة في الدليل تذكر المطلب وتسمّي الـADR،
  فلا يتباعد نصّان عن قرارٍ واحد.

هذه القواعد منصوصةٌ في `../../ENGINEERING_PLAYBOOK.md` §٧.١٦ (‏`M-104`–`M-106`).
